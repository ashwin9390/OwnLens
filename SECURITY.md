# Security Policy

## Security Model

OwnLens deals directly with continuous visual capture, on-device data redaction, and access controls for autonomous systems. Reducing exposure of sensitive user data is core to the project's purpose — see the Status disclaimers in `README.md` for what the current spec does and does not guarantee.

## Reporting a Vulnerability

If you discover a security vulnerability in the OwnLens specification, schemas, or reference redaction code, please do not open a public issue.

Instead, report it privately to the maintainer via a GitHub Security Advisory on this repository (Security tab → "Report a vulnerability"), or via the contact method listed in `README.md`.
